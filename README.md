# ✨ UAF_DDI
**The only ADB + Fastboot driver/program installer you'll ever need!**<br>
Requires admin privileges.

# 🧩 Dependencies
### System components
ℹ Information: System components cannot be installed using this tool.
- **PNPUtil** for *installing drivers* by Microsoft
- **PowerShell** for *various tasks, such as update checking* by Microsoft
### Programs
- **7-Zip** for *extracting files/drivers* by Igor Pavlov

# 💻 Requirements
- **Internet access** for *downloading drivers/dependencies*
- **x86/x64-based PC** for *driver compatibility reasons*
- **Windows 10/11+** for *system compatibility reasons*
  You can try older Windows versions, but they will never be officially supported and things may break!
